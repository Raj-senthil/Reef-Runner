# 🐠 Reef Runner(My First Game)

An ocean-themed endless runner game that runs in your browser. Play as Finn the clownfish, dodge sharks, coral and jellyfish, and collect pearls and starfish.

## How to play
- ← → switch lanes
- ↑ or Space to jump over coral
- ↓ to slide under jellyfish
- P to pause, M to mute
- On a phone: swipe to move, tap to jump

## Power-ups
- 🧲 Magnet: pulls in pearls
- 🫧 Shield: absorbs one hit
- ⚡ Turbo: smash through everything

The game gets faster as your score grows.

## Run it
Open `index.html` in any browser. No install needed.

## Built with
Plain HTML, CSS and JavaScript. No libraries.
